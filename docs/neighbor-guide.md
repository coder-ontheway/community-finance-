# 社區財務查詢網站使用說明（給鄰居）

## 如何進入

1. 用手機、平板或電腦打開網站網址。
2. 輸入管理委員會告知的「社區共同瀏覽密碼」，按「進入」。
3. 同一台裝置通常可保持登入一段時間。若密碼已更換，會請你輸入新密碼。

> 密碼請勿轉傳到社區以外的地方。連續輸入錯誤多次會暫停 15 分鐘。

## 可以看到什麼

| 頁面 | 內容 |
|---|---|
| 財務儀表板 | 選擇月份，看當月總收入、總支出、收支差額、今年累計、修繕支出、支出類別占比、每月趨勢、與上月及去年同月比較。**點擊任何數字或圖表，都能看到組成它的每一筆明細。** |
| 月報表 | 每月報表印出的小計、結餘，與系統逐筆加總的比對結果。 |
| 明細搜尋 | 依年度、月份、科目、廠商、收入或支出、關鍵字（例如「電梯」「防水」「監控」）搜尋，可下載 CSV 用 Excel 開啟。 |
| 收支科目 | 每個科目的每月金額、今年累計、與去年比較。 |
| 廠商分析 | 每家廠商分開顯示三種金額（見下方說明）。 |
| 修繕分析 | 每月、每年修繕支出、修繕分類、廠商、單筆排行、關鍵字查詢、待查核線索。 |

## 閱讀時請注意

- **三種結餘不一樣**：「報表記載的結餘」是月報表印的數字；「系統計算的結餘」是把每筆明細加總；「銀行實際餘額」取自銀行存摺。三者可能因預收款、時間差等原因不同。
- **廠商的三種金額分開看**：
  - A：社區付給廠商的錢
  - B：廠商付給社區的錢（例如退款、回饋金）
  - C：付款方未確認的收入
  
  月報表只記載收支，**看不出廠商的成本或利潤**，A 與 B 的差額不是利潤。
- **待查核線索**是系統依規則自動產生的提示（例如某月修繕費特別高），不是指控，也不代表有不當行為。有疑問歡迎向管理委員會詢問。
- 部分明細涉及個人隱私（例如個人健康、住戶欠費），只顯示該科目的彙總金額，不顯示摘要。
- 只會看到管理委員會已逐筆核對並公開的月份。

## 這是唯讀網站

網站上沒有任何新增、修改、刪除功能，資料庫也設定為鄰居只能讀取。任何人都無法透過網站或其他程式修改社區財務資料。
